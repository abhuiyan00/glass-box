    The numbers, and how each one is counted

    Every figure below is computed when this site is built, from the same files the pages are written from. None of them is typed into a template. Where something has not been measured the cell says so — an unmeasured value is never shown as a zero.

    What is in here

    CountsHow it is counted
    28source repositories readDistinct first path segments of every page's sources: field. There is no list of repositories in any code — a sixteenth appears the moment a page cites it.
    293pages in the private wikiEvery markdown page under wiki/ carrying one of the six page types. Catalogue and index files are not counted.
    288pages that may be publishedSession records are categorically unpublishable, so the publishable universe is smaller than the wiki. The difference is not an oversight; it is a rule.
    281pages public on this siteFlipping a page public is a human decision made once per page, and it is the one step in the whole pipeline that is never automated.
    45decisions recordedPages of type decision: one choice each, with a date.
    36of those that name the alternative they rejectedCounted structurally — the page must carry a rejected-alternatives heading or table, not merely mention a rejection in prose. An earlier hand count said 35 and was wrong in the flattering direction.
    11claims retired since they were first writtenRows in a dated claim table whose validity has an end date. The old claim is never deleted — it keeps its dates and the page says what changed.

    Does the search actually work

    The honest figure is the first one, and it is not flattering. It is the one printed largest anyway.

    CountsHow it is counted
    0.58hit@5 on phrasings the search has never seenOf 31 held-out questions, the share where the right page came back in the top five. The gate is 0.70. The questions were written by the author, so this is reproducible, not independent — it is the direction of travel, not a benchmark.
    1.00hit@5 on the set the search was tuned against34 questions. Anyone can publish this number; it proves only that nothing regressed.
    not measuredshare of unanswerable questions it correctly refusesHeld back on purpose. It measures 5 cases and the gate is 0.90 — a perfect score on that few reads as a proven property and is not one. The cell fills in when the negative set reaches 20.
    2changes the evaluation rejected that looked like winsA word-stemming change that read as obviously better and measured worse, and a scoring path whose ties were broken by set iteration, so identical code scored 0.73, 0.53 and 0.60 on three runs. The evaluation outranks the author.

    CountsHow it is counted

    20.00hard spending capReached, the tooling aborts rather than continuing.

    What this page does not prove

    That the pages are correct. These figures measure coverage, retrieval and process — whether a claim can be traced to a source, not whether the source was right. The pages carry their own confidence levels and name their own gaps; see what it does not know.
