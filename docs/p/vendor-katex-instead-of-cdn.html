    Vendor KaTeX Instead of CDN

    Decision. Copy katex — katex.min.js, katex.min.css, auto-render.min.js and all 20 KaTeX_*.woff2 font files — into exam_prep/vendor/katex/ and load them by relative path, rather than linking a CDN build.

    Date. The vendored files carry the earliest mtimes in physics-exam-prep, 2026-06-27; first committed 2026-07-10.

    #Why

    The requirement is stated as the app's headline, not as a footnote:

    "No build step. No server. No internet. Open one HTML file and start revising."

    Physics/README.md, 2026-07-10

    and the vendored folder is annotated with the consequence:

    " └── katex/ # bundled KaTeX (offline math) — no CDN needed"

    Physics/exam_prep/snapshot.md, 2026-06-30

    The failure a CDN would cause is specific to this deliverable: a study app is used the night before an exam, plausibly with no connection, and math that fails to render is not degraded output — it is a blank formula where the answer should be. Fonts make it worse than a normal CDN dependency, because katex.min.css references 20 font files, so a partially-cached CDN load renders text with the wrong glyphs rather than failing cleanly.

    #Alternatives rejected

    Option Why not
    KaTeX from a CDNneeds the network at exactly the moment the app promises not to; the CSS pulls 20 fonts, so partial failure is silent and ugly
    MathJax (vendored or CDN)heavier, asynchronous, and its extra LaTeX coverage buys nothing for a physics syllabus. TODO: never actually compared in-repo — see below
    Pre-render formulas to imagesbreaks selection, scaling and dark mode; the knowledge base stores math as \(…\) strings and renders them at runtime
    Install via npm and bundlewould introduce the package.json and build step the whole app exists without — zero-dependency-no-build-step

    TODO: the KaTeX-vs-MathJax comparison above is reconstructed engineering reasoning, not a recorded rationale. No file in the repo weighs the two, and it was not asked at interview. confidence: low on why KaTeX specifically; high on the vendoring decision and its stated reason.

    #What makes it hold

    Vendoring alone would not guarantee the offline promise — the service worker still has to precache the files. All 23 KaTeX assets are listed in sw.js's CORE array, and tools/qa.mjs check 8 fails if anything index.html loads is missing from that list. The install strategy that keeps a single missing file from aborting the whole cache is cache-individually-not-addall.

    #Cost, stated plainly

    ~304 KB of JS/CSS plus 20 font files committed permanently, with no version pin and no update path recorded anywhere. The copy is frozen at whatever was current on 2026-06-27. For a frozen coursework artefact that is the right trade; for anything maintained it is a silent staleness debt.

    The same instinct appears one repo over as vendor-react-over-babel-cdn, where the CDN was not a risk but an observed failure — a blank page under file://. Two repos, same conclusion, reached from opposite directions: physics-exam-prep vendored pre-emptively, discrete-mathematics-laboratories vendored after being burned.
