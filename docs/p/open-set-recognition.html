    Open-Set Recognition

    A classifier trained on K categories must, by construction, map every input onto one of them. Open-set recognition (OSR) removes that assumption: the model may name a known class or reject the input as unknown, and both are correct answers.

    The failure it fixes is not inaccuracy but silence. Train on cats, dogs and horses, show it a frog, and the network returns whichever known class looks most similar — usually with high confidence. A softmax layer makes this unavoidable: its outputs sum to 1 across the known classes, so there is nowhere for probability mass to go except onto a wrong label.

    Ability Closed-set Open-set
    Classify a known class✓✓
    Recognise "this is none of the known classes"✗✓
    Cope with a changing, open world✗✓

    #Why it matters, per the study

    Three arguments, in the order research-methodologies-open-set-recognition makes them: safety (a face-recognition system that must choose will match a stranger to a friend; a perception stack will read a stroller as a motorcycle), annotation cost (supervised learning needs every class labelled by hand and can never be exhaustive), and fit to deployment (the real world is open-ended by nature).

    #The three families

    Family Method Core idea
    Traditionalconfidence / distance thresholdreject anything scoring below a chosen cut; simple and effective, the hard part is picking the threshold
    distance-based rejectionreject samples far from every known-class prototype in feature space
    StatisticalExtreme Value Theorymodel the tail of the score distribution, where outliers live
    OpenMaxreplace softmax with a layer that hands probability mass to an explicit unknown class — openmax-and-extreme-value-theory
    Deepmetric learningcompact, well-separated features leave empty space for unknowns to fall into
    generativesynthesise unknown-looking samples, or use reconstruction error as the signal — generative-adversarial-network
    self-supervised / contrastive / Bayesian / evidential / ViTstronger representations, uncertainty estimated directly

    — already a good open-set detector (Vaze et al., ICLR 2022). Improving plain accuracy tends to improve the confidence and feature scores that OSR relies on, which makes the two goals far more aligned than the taxonomy suggests. It also sets an uncomfortable bar for any dedicated method: it must beat a merely better-trained baseline.

    #Where the study takes it

    The generative branch is developed in full and ends on OpenGAN (Kong & Ramanan, ICCV 2021), which moves the discrimination into feature space and selects the model checkpoint on a small held-out open set. Benchmarks are cited, not reproduced — report-cites-benchmarks-rather-than-reproducing.
