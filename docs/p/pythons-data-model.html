    Python's Data Model

    Python's protocols are duck typing with a contract: implement the right dunder methods and your class participates in ==, <, in, len(), for, [], hashing and printing as if it were built in. Labs 04 and 05 of python-programming-laboratories are the exercise of writing them by hand.

    #Equality, ordering and hashing

    The three rules that bite:

    1. __eq__ must return NotImplemented, not False, for foreign types. Returning False asserts inequality and blocks Python from trying the other operand's __eq__. Returning NotImplemented delegates, and only if both sides decline does Python fall back to identity.
    2. Defining __eq__ sets __hash__ = None. Python un-hashes your class automatically to stop the classic bug where two equal objects hash differently. If the object is genuinely immutable you must define __hash__ explicitly — the lab does.
    3. functools.total_ordering fills in the rest. Define __eq__ and one of __lt__/__le__/ __gt__/__ge__, and the decorator derives the other three. Fewer methods, fewer chances for the relations to disagree.

    weblog.LogEntry takes the shortcut the labs teach the long way: @dataclass(frozen=True, slots=True) — frozen generates __eq__ and __hash__ consistently and blocks mutation, slots drops the per-instance __dict__ for memory, which matters when streaming a log. Its __str__ round-trips back to the source format, see common-log-format-parsing.

    The class hierarchy taught alongside it — HttpRequest / CorrectHttpRequest / MalformedHttpRequest, with a from_line classmethod factory — is kept in the tree beside weblog.LogEntry on purpose: keep-the-teaching-version.

    #The container protocol

    Lab 05 implements __getitem__, __len__, __contains__ and __iter__ on an AccessLog, and makes two API choices worth stealing:

    • __getitem__ returns a copy, and an empty list rather than None for a miss. A caller can always iterate the result, so no call site needs a None guard. The same instinct as size=0 "so that summing it never needs a guard".
    • quietest_hosts returns all ties. Silently picking one of several equal minima is a bug that only appears in the data, not in the code.
