    In short

    OpenAI's terminal coding agent, and the second executor in agent-orchestrator

    Codex CLI

    OpenAI's terminal coding agent, and the second executor in agent-orchestrator. Driven as codex exec --json with -C <workspace>, so the answer comes from a structured stream rather than from parsed prose — the same contract as claude-code-cli, reached through different flags.

    #Where it differs, and why that matters

    • Sandboxing is configuration, not a mode flag: -c sandbox_mode=read-only | workspace-write | danger-full-access, passed identically on a fresh invocation and a resumed one. A resume that quietly dropped the sandbox setting would be the worst kind of bug — invisible and privileged.
    • Text only. It cannot open an image or extract a PDF, so read-capability-routing moves any subtask that declares those reads to Claude, whatever the planner asked for.
    • No plugin mechanism. Skills reach it as files it is allowed to open plus a prompt section naming the index, rather than as a loaded plugin. The prompt is therefore built per attempt, not once — a prompt written for the planner's chosen agent describes the wrong mechanism after a fallback (agent-skills-checked-into-the-repo).

    #Effort

    Codex exposes a reasoning ladder with a per-model ceiling. The orchestrator clamps a request above that ceiling instead of sending it and hoping — reasoning-effort-as-a-portable-label.

    #Observed failure mode

    A spent subscription is the routine one, and it arrives as prose on stderr:

    "You've hit your usage limit. Upgrade to Pro (https://chatgpt.com/explore/pro), visit https://chatgpt.com/codex/settings/usage to purchase more credits or try again at Aug 8th, 2026 9:36 AM."

    vs-llm-orchestrator/agent-orchestrator/extension/harness/fixtures/multi-fallback.jsonl, 2026-08-07

    The orchestrator quotes that verbatim rather than paraphrasing it, because the reset time is the only part a reader can act on, and remembers the agent as exhausted for the rest of the run instead of paying for the same refusal again.
