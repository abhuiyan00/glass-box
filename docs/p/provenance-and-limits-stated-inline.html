    Provenance and Limits Stated Inline

    The boundary of a claim is written next to the claim, not in a footnote or an appendix. Confirmed in 13 of 15 repositories and unusually strong in five. This is the habit that makes the source set trustworthy despite documentation-drift elsewhere.

    #The forms it takes

    A negative result advertised in the headline. Optimization Methods puts its blind GA losing to a greedy heuristic in the README's own comparison table, under the heading "Two modifications (one negative, kept honest)". See blind-baseline-comparison.

    A typed provenance field. Farley carries CarSpec.source = "built-in" | "fueleconomy.gov" | "estimate", VisionResult.method = "cloud" | "on-device", and merges its event calendar by precedence live > listing > typical. Provenance is a value in the type system, not a comment.

    Naming the variant not used. Data-Warehousing-and-Business-Intelligence implements the simple-moving-average RSI and names Wilder's exponential smoothing as the variant it did not use — see relative-strength-index.

    Scoping what the work is not. Research Methodologies states its benchmark table is "not experiments run for this coursework"; Cybersecurity-Engineering-Laboratories has a dedicated "A note on scope"; privacy-policy says "not legal advice"; Physics marks its Node tools "not shipped to the browser".

    Self-reported doc bugs. Optimization Methods/final_project/docs/DATA_VERIFICATION.md flags that HOW_TO_RUN.md "names two scripts that don't exist" — recording the defect rather than fixing it.

    Retroactive labelling. browser_game_stickfps/PROGRESS.md marks one round entry "logged retroactively during the round-9 documentation pass — reconstructed from the shipped code", and separates harness quirks from product bugs by name.

    Reproducibility stated as a limit. Optimization Methods reports that fresh OpenStreetMap downloads no longer reproduce the paper's distances because "OSM has drifted" — a negative reproducibility result kept in the audit rather than quietly dropped.

    #The counter-current

    The habit is strongest deep in a repo and weakest at the top. Farley's lib/*.ts headers state scope and fallback behaviour meticulously while its public README claims a test suite that does not exist. labour-fraud-analysis has the most developed threat model in the set and a README claim ("test-verified in CI") that overstates what CI enforces, since the leak scan skips on a clean runner. Depth correlates with honesty; the guided tour in readme-as-guided-tour is where accuracy is thinnest.
