    In short

    Python's imaging library

    Pillow

    Python's imaging library. Used in lab 11 of python-programming-laboratories for cover-image processing inside a four-stage document pipeline — fetch, extract, render, assemble — that turns a scraped book into a .docx with generated charts.

    #The version break it documents

    "Two library APIs moved. Image.ANTIALIAS and ImageDraw.textsize were removed in Pillow 10; findAll(text=True) was removed in BeautifulSoup 4.13."

    Python-Programming-Laboratories/labs/11_report_pipeline/README.md, 2026-07-25

    Both removals were long-deprecated aliases that a great deal of tutorial code still uses:

    • Image.ANTIALIAS → Image.Resampling.LANCZOS. The constant was an alias, not a distinct filter, so the port is a rename with no behaviour change.
    • ImageDraw.textsize → textbbox / textlength. This one is a behaviour change: textbbox returns a bounding box with offsets rather than a bare (w, h), so any layout arithmetic built on the old return value needs adjusting rather than renaming.

    Writing the diagnosis beside the code is the point — the commit history has none of this, since everything landed in one day: import-finished-work-into-git. The pattern is document-the-failure-mode-next-to-the-fix; the beautifulsoup half of the same note is recorded there.

    #Also handled: fonts off Windows

    The pipeline includes a font fallback for non-Windows machines, because ImageFont.truetype on a hard-coded Windows font path fails outright rather than substituting. Same class of problem as 48ba16d Fix UnicodeEncodeError in the lab3 demos on Windows consoles in discrete-mathematics-laboratories, from the opposite direction — one repo's code broke on Windows, this one's would break off it.

    Charts in the same pipeline come from matplotlib with Agg and a plt.close() per figure across 41 chapters; every generated artefact is gitignored as reproducible from source.
