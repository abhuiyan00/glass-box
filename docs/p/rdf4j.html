    RDF4J

    Eclipse RDF4J — the successor to the OpenRDF Sesame framework — is a Java library for storing, inferring over and querying RDF. Information-Systems-Modelling lab 5 uses 3.6.3, pulled in via rdf4j-bom + rdf4j-storage, and it is the only triple store in the source set. (The other graph technology in the corpus is neo4j, which is a labelled property graph, not RDF — different data model, different query language.)

    #What lab 5 uses it for

    Six classes, ~one job each:

    Class Role
    RepositoryFactoryinMemoryWithRdfs() — an in-memory store wrapped in an RDFS inferencer
    OntologyLoaderloads Turtle from the classpath into a named context
    Vocabularynamespace and IRI constants
    SampleDataWriteradds triples through the model API rather than from a file
    QueryRunnereight SPARQL SELECT queries
    Appmain — build store, load TBox + ABox, add triples, query, shut down

    The store is in-memory only. Nothing persists between runs, there is no native store directory, no HTTP SPARQL endpoint and no RDF4J Server/Workbench deployment. Everything is rebuilt from ontology.ttl and sample-data.ttl on each main.

    #The inferencer is the point

    RepositoryFactory.inMemoryWithRdfs() is one line of configuration that changes what the queries mean. Two of the eight queries exist to demonstrate it — listInferredKnowsLinks returns symmetric knows links nobody asserted in that direction, and listTransitiveCommunityMembership walks a transitive chain. The other six are ordinary retrieval and would work over a plain store.

    That split — some queries answered by the data, some by the reasoner — is the whole content of ontology-modelling-tbox-abox made executable.

    #An outlier in the build

    Lab 5 is the only Java module in the repo on Java 11 while labs 2–4 are on Java 21, and the only one whose pom.xml contains no Spring at all: rdf4j-bom, rdf4j-storage, slf4j 1.7.36, log4j2 2.17.2, maven-compiler-plugin, exec-maven-plugin 3.1.0. It is also the only Maven module without an mvnw wrapper, so the root README's promise of "or use the bundled wrapper" does not hold here — an instance of documentation-drift. See maven.

    The package name is pl.edu.pwr.modellingclub, not the pl.edu.pwr.tkubik.ism used by labs 2–4, and the directory is named sesameExample_sol — Sesame being RDF4J's former name.

    #What is not verified

    There is no test for anything in lab 5. lab5/README.md reports that the store "loads 465 statements and answers eight queries"; the eight queries are verifiable by reading QueryRunner, the statement count is single-source prose with nothing asserting it.
