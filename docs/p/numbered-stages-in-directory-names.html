    Numbered Stages in Directory Names

    Order is encoded in filenames and directory names, not in a table of contents. Present in seven repositories. What varies — and it is the interesting part — is whether the number means run this first or read this first.

    #Numbering as run order

    Oracle-Database-Laboratories and Data-Warehousing-and-Business-Intelligence both number executables, and the number is a dependency edge:

    • sql/01_schema/ → 02_queries/ → 03_plsql/ → 04_object_relational/, and inside each, 01_drop_all.sql → 02_create_tables.sql → 03_seed_data.sql
    • sql/01_analytics/, sql/02_star_schema/{01_create,02_load}, project/twtr/sql/{01_staging, 02_star_schema, 03_technical_indicators}

    You cannot load before you create — see etl-load-order — so the digits are load-bearing. The Data-Warehousing README makes it explicit: "The mart must be created before it is loaded."

    #Numbering as chapters

    Discrete-Mathematics-Laboratories (lab1_Max_Cut … lab6_Neo4j), Python-Programming-Laboratories (01_first_steps … 13_sqlite_and_gui), Cybersecurity-Engineering-Laboratories (01-02_classical_ciphers_and_entropy … 14_web_security_injection) and Information-Systems-Modelling (lab1/ … lab7/) use the number as a reading order, with each directory carrying its own README and the root README walking them in sequence.

    Information-Systems-Modelling states the chapter metaphor outright — "each lab picks up exactly where the last one left off" — and it is literally true: lab 3 is lab 2 plus authentication, lab 4 is lab 3 plus AOP and uploads. See forward-copy-lab-progression.

    #Numbering as prose chapters

    Only Farley puts the numbers on documents in a docs/ directory: 01-architecture.md, 02-roadmap.md, 03-android-permissions-and-legal.md, 04-accessibility-service.md, plus a newest-first CHANGELOG.md and a README index table mapping each chapter to what it covers. See numbered-docs-chapters.

    #Where the numbering moved inside the files

    Several repos have the instinct without the filenames. Optimization Methods numbers chapters 01–24 inside chapters.js, sections §1–§10 inside ARCHITECTURE.md, figures fig1–fig11, and operator combinations C01–C32 — but its docs/ filenames are unnumbered SHOUTY topics. Information-Systems-Modelling/lab7 numbers its BPMN processes p1-backup.bpmn … p8-eol.bpmn with matching SVGs and specs.js constants. labour-fraud-analysis numbers only its notebook and its prose headings.

    #Why it works here

    These repos are read by someone arriving cold, which is the same premise as readme-as-guided-tour. A sorted directory listing is a table of contents that cannot drift out of sync with itself — a useful property in a source set where prose does drift, per documentation-drift. The numbering survives even when the README describing it goes stale.
