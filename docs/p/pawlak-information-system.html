    Pawlak Information System

    A Pawlak information system is the pair S = (U, A): a universe U of objects, a set A of attributes, and for each attribute a ∈ A a function a: U → V_a assigning every object a value. It is the formal substrate of rough set theory — deliberately weaker than a relational schema, because the point is what you can say when objects are only distinguishable through their attribute values.

    #Indiscernibility

    For any attribute subset B ⊆ A, the indiscernibility relation IND(B) holds between two objects when they agree on every attribute in B. It is an equivalence relation, so it partitions U into equivalence classes — the finest distinctions B can make. Rough set theory builds lower and upper approximations of a target set from those classes: what B definitely proves, versus what it merely permits.

    #As a property graph

    Lab 6 of discrete-mathematics-laboratories models S = (U, A) as a bipartite graph rather than a table:

    (:Object)-[:HAS_VALUE {value}]->(:Attribute)

    39 objects × 25 attributes = 975 HAS_VALUE edges. Putting the value on the relationship rather than on the object is the modelling move that makes it an information system rather than a row: attributes become first-class, so "which objects agree on this attribute" is a one-hop traversal instead of a column scan.
