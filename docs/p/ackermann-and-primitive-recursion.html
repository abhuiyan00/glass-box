    Ackermann and Primitive Recursion

    The Ackermann function is the standard witness that total computable is strictly larger than primitive recursive. It always terminates, yet no bounded-for-loop program computes it: its growth outruns every function you can build from composition and primitive recursion.

    A(0, n) = n + 1
A(m, 0) = A(m − 1, 1)
A(m, n) = A(m − 1, A(m, n − 1))

    The closed forms per row make the escalation legible: A(1,n) = n+2, A(2,n) = 2n+3, A(3,n) = 2^(n+3) − 3, and A(4,n) is a tower of powers. Lab 4 of discrete-mathematics-laboratories short-circuits A(4,2) to the literal 2**65536 − 3 because evaluating it honestly is not an option.

    #Making it observable

    Rather than tabulate values, the lab instruments the recursion:

    • Memoised evaluation with sys.setrecursionlimit(500_000) — the recursion depth is the point, not an obstacle.
    • A recursive-call counter, so the cost is displayed alongside the result. The call count grows far faster than the value for small m, which is the actual lesson.
    • A matplotlib dashboard — GridSpec panels, a Slider over m/n, a LogNorm heatmap, because a linear colour scale shows nothing at all here.

    This is the clearest single instance of make-the-formal-object-observable in the repo.

    #The inverse: α

    α(n), the inverse Ackermann function, is the reason it matters outside logic. It grows so slowly that for any input arising in practice α(n) ≤ 4. It is the true complexity factor in union-find with path compression and union by rank — which is exactly what Kruskal's algorithm uses in the same repo's lab 5, see graph-connectivity-and-resilience. "Effectively constant" in an algorithms textbook is this function.

    #Beside it: Stirling's approximation

    The same lab directory pairs Ackermann with Stirling's approximation, n! ≈ √(2πn)·(n/e)^n, as the opposite kind of asymptotic result — a growth rate you can control rather than one that escapes. Every quantity is computed in log space via math.lgamma, so n! never overflows, and the lab plots relative error and the n!/Stirling(n) ratio.
