    Documentation Drift

    Docs describe the intended system; code implements a subset; the docs are never walked back. Found in 12 of 15 repositories, with 11 distinct instances in two of them. This is the characteristic failure mode of the source set, and the direct cost of import-finished-work-into-git — nothing forces a doc to be re-read when the work lands in one commit.

    #The sharpest instances

    A test suite that does not exist. Farley/README.md line 174: "Tested with Vitest and Playwright." There is no vitest, no playwright, and zero test files; CONTRIBUTING.md says the opposite outright. Resolved at interview:

    "Aspirational — tests were planned."

    interview, 2026-07-28

    A shipped feature that is a stub. Farley's README and four docs describe Android ML Kit OCR as the on-device engine. ML Kit is in no build.gradle and OcrReader.readNow() returns null. The working reader is the accessibility node-tree parser — see node-tree-read-before-ocr.

    A deleted transport still in the build. browser_game_stickfps/server/Dockerfile keeps EXPOSE 10000/udp after UDP was removed, and all four .tooling agent files still instruct agents to use "Geckos.io" and "Fly.io" — see websocket-tcp-over-geckos-udp.

    Undocumented cache generations. Physics/exam_prep/sw.js declares physprep-v4; snapshot.md says v3; the README says v2. At least two offline-cache changes were never recorded. TODO: what broke between them is unresolved — "Don't remember the cache history" (interview, 2026-07-28), so no narrative is asserted here.

    A documented file that was never committed. Information-Systems-Modelling/lab6/README.md lists snapshot.md in its file tree. It does not exist, on disk or in history.

    A guide predating its own code. IT Applications in Business and Commerce/.../guide.txt is stamped "Updated 2026-05-13", describes the pre-rewrite baseline as "What exists today", is banner-stamped for one track while its body targets another, depends on a recon_lap.py that does not exist, and hardcodes a machine-local D:\... path.

    Counts that disagree with themselves. Physics alone: sims.js documented as 9 simulators in one section and 13 in another; qa.mjs as 32 checks vs 34; the bank as 62 questions vs a generated audit reporting 75.

    A licence claim three months stale. Optimization Methods/first_project/README.md still says "No license file is currently included in this repository" long after MIT was added at the root.

    The rejected design shipped in a sibling format. Data-Warehousing-and-Business-Intelligence argues at length against modelling RSI as a dimension, then ships Dim RSI.dim doing exactly that — which is also an instance of keep-the-superseded-version-in-tree and is covered on rsi-as-measure-not-dimension.

    #The counter-habit that bounds it

    browser_game_stickfps never rewrites a retired decision — it stacks a dated SUPERSEDED banner on top of the original text. docs/SRS.md FR-9.3, DESIGN_PROMPT.md §3 and docs/DESIGN-BRIEF.md §2 all still carry the grayscale mandate under such a banner. This trades internal consistency for an auditable history; see superseded-in-place-documentation.

    #Where drift is absent

    Oracle-Database-Laboratories — docs match code closely, essentially no drift. It is also the repo whose prose is written as inline SQL comments rather than as a separate document, which removes the gap where drift lives.
