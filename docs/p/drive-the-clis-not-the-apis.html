    Drive the CLIs, Not the APIs

    agent-orchestrator spawns claude and codex as subprocesses in structured streaming mode and treats their output as the authoritative answer. It does not call Anthropic's or OpenAI's APIs.

    #Why

    The executors need an agent loop — read files, edit them, run tests, iterate. Two ways to get one: write it here against the APIs (tool definitions, file and edit and shell tools, permission handling, retry, context management, sandboxing), or spawn a binary that already is one.

    The deciding argument is not effort, it is money. The author already pays a monthly subscription for both CLIs, and those subscriptions are consumed by the CLIs. API access is billed separately, per token. Writing the agent loop here would mean paying twice for something already owned — and paying the expensive way. It is why a two-subtask run costs about $0.002: only the openrouter planning calls are metered, and the actual work runs on subscriptions.

    The second argument is that the vendors' loops are better than the one that would get written here, and they improve without this project doing anything.

    #What it costs

    Every flag is an interface owned by someone else and versioned on their schedule. The test suite can assert the argv sent but not the behaviour obtained, so a renamed permission flag passes every test and fails on first contact — the standing top risk, and the reason each flag records the CLI version it was verified against.

    It also forces the shape of everything downstream: no interactive permission prompt exists in a non-interactive process, so autonomy has to be decided up front (autonomy-decided-before-the-run); capability differences between binaries become routing rules (read-capability-routing); vendor reasoning parameters have to be normalised (reasoning-effort-as-a-portable-label).

    #Rejected

    Call the APIs and write the loop. Rejected on cost — double billing for a worse loop. A hybrid — CLIs when logged in, APIs otherwise. Rejected as two code paths where only one is exercised daily; the untested path is the one that runs on the bad day.
