    Synthesise Rather Than Redact

    Decision. Do not publish the sensitive corpus with identifying values blacked out. Publish a wholly invented dataset whose every value is generated, and whose relational structure and statistical patterns are carried over from the real matter unchanged.

    Date. 2026-07-11, labour-fraud-analysis. This is the repository's central methodological choice — everything in src/ exists to execute it.

    #Why

    Two requirements pull in opposite directions, and the repo states both as hard rules:

    "No real value may ever reach version control — not in the data, not in the docs, and not in the code that does the anonymizing."

    labour-fraud-analysis-a-forensic-data-investigation/docs/methodology.md, 2026-07-11

    "The result must stay analytically honest — same relational structure, same statistical patterns (bulk permits, entity succession, shared-contact control, financial anomalies), so the analysis demonstrates real skill rather than toy data."

    labour-fraud-analysis-a-forensic-data-investigation/docs/methodology.md, 2026-07-11

    Redaction satisfies the first and destroys the second. A blacked-out contact field cannot show that sixty-six workers share two inboxes; a blacked-out permit number cannot show that a day's batch runs contiguous. The signals in this case are the identifiers' relationships to each other, so removing the identifiers removes the case. Synthesis is what reconciles the two constraints:

    "Reconciling those is the whole trick: replace every value, preserve every relationship."

    labour-fraud-analysis-a-forensic-data-investigation/docs/methodology.md, 2026-07-11

    That reconciliation is structure-preserving-anonymisation, made consistent across tables and free text by deterministic-seeded-substitution and kept parseable by format-preserving-invalid-identifiers. The signals that survive are the subject of shared-identifier-clustering and convergent-evidence.

    #Alternatives rejected

    Option Why not
    Publish the redacted sourcethe source was already a redacted real-world matter; redaction leaves the analytical patterns unreadable, which is the requirement above
    Generate toy data from scratchnamed explicitly as the failure mode — an analysis over invented-from-nothing data "demonstrates real skill" of nobody
    Publish nothing; describe the work in proseleaves no artefact to run, review, or verify; the pipeline and its gate are the deliverable
    Aggregate/statistical release onlynot named in the repo. TODO: unrecorded whether it was considered

    #What makes it defensible rather than a claim

    Synthesis on its own is an assertion. What makes it checkable is that a separate program tries to break it: the disclosure-gate rebuilds a blocklist from the private source at run time and greps the entire published tree for survivors, backed by a stem guard, a regex sweep and structural integrity checks. The scrubbing code is careful not to become the leak it prevents:

    "This script may reference real strings at run time because it reads them from the private source; it contains none in its own text."

    labour-fraud-analysis-a-forensic-data-investigation/src/anonymize.py, 2026-07-11

    #The costs, stated

    • The gate's strongest checks cannot run in public CI. The leak scan and stem guard need the private corpus, which no public runner has. The README's "test-verified in CI" claim is therefore stronger than what a clean runner enforces. confidence: high, interview-confirmed 2026-07-28 — see github-actions and generated-docs-checked-by-ci-diff.
    • Synthesis is not total. Column names retaining source-jurisdiction registers, an allow-list naming a country and its adjective, a national-ID regex, a country-code phone pattern and a locale string in the viewer all survive in committed code. None is a person-like value; together they narrow the source jurisdiction and the worker-origin corridor, which sits against the methodology's claim that no origin-signalling scrap survives.
    • Every specific case number is prose. The narrative's figures are typed into docs/, and only some are recomputed by the notebook or dashboard. See chain-of-custody for what is anchored.
    • Verification is one-machine. Re-running the pipeline end-to-end needs the private source, so nobody else can confirm the published data is what the committed seed and code would produce — reproducible-analysis.

    #Publish stance

    Every wiki page for this repository was publish: false, per the interview. That blanket was lifted on 2026-07-30; what it was standing in for was not.

    The synthesis decision does not by itself establish a right to republish the derived form: the underlying matter is described in the repo as live and under review, and no clearance from the corpus holder is evidenced anywhere. What is public now is the method — seeded substitution, the disclosure gate, the verification step — and not the matter, the corpus, or the dataset the method produced. See the open gaps on labour-fraud-analysis.
