    KaTeX

    Client-side LaTeX math renderer. It is the only third-party dependency anywhere in physics-exam-prep, and the reason that repo contains 20 .woff2 font files — a fact that looks like build residue until you know what it is.

    #How it is included

    Three files under exam_prep/vendor/katex/, committed into the repository:

    File Size Role
    katex.min.js277 KBthe renderer
    katex.min.css23 KBthe stylesheet — this is what references the fonts
    auto-render.min.js3.5 KBscans the DOM and renders delimited math in place
    fonts/KaTeX_*.woff2×20AMS, Main, Math, SansSerif, Script, Size1–4, Caligraphic, Fraktur, Typewriter

    Loaded by two plain <script src="vendor/…"> tags and one <link rel="stylesheet"> in a hand-authored index.html. No bundler, no package manager, no import map — see zero-dependency-no-build-step.

    The auto-render plugin is why the knowledge base can store math as ordinary strings: js/data.js writes \(…\) delimiters inline and the renderer finds them after the page is built, so nothing in the app has to know KaTeX exists.

    #Why it is vendored rather than fetched

    Recorded as vendor-katex-instead-of-cdn. The one-line justification is written into the app's own structural map:

    " └── katex/ # bundled KaTeX (offline math) — no CDN needed"

    Physics/exam_prep/snapshot.md, 2026-06-30

    A study tool whose formulas silently fail to render when the Wi-Fi is off is not a study tool. All 23 KaTeX assets are listed in the service worker's CORE precache array, and tools/qa.mjs statically checks that every formula in the knowledge base actually parses — so a malformed LaTeX string fails the harness rather than the exam-eve revision session.

    #Why KaTeX rather than MathJax

    The functional argument is that KaTeX renders synchronously and self-contained, with no font fetching at runtime beyond the files already on disk, which is precisely what a file:// deliverable needs — offline-first-static-deliverable. MathJax's fuller LaTeX coverage buys nothing for a syllabus of physics formulas.

    #Cost of the choice

    ~304 KB of JS/CSS plus the font files, committed permanently and updated by hand or not at all. There is no version pin and no update path recorded anywhere — the vendored copy is frozen at whatever was current on 2026-06-27, the earliest mtime in the repo.
