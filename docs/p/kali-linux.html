    Kali Linux

    A Debian-derived distribution that ships several hundred security tools preinstalled and preconfigured. It is the attack host for every practical lab in cybersecurity-engineering-laboratories from lab 07 onward.

    #The point of a tooling distribution

    Not the tools themselves — almost all are separately installable — but that the environment is someone else's problem. Package versions that work together, tools on the path, a repeatable image you can revert. In a fourteen-lab course where each session uses a different tool (openssl, wireshark, nmap, metasploit, owasp-zap, Ettercap, theHarvester, dnsenum, netcat), the alternative is spending each session installing rather than learning.

    The lab reports show the value negatively: the failures that are recorded are overwhelmingly environment failures — a GUI front end that would not install, a tool erroring on invocation, a local service that would not start — and they cluster in the labs that reach outside the preinstalled set.

    #The lab range

    The whole environment is VirtualBox VMs on one workstation, which is the second half of the same idea:

    VM Role
    Kali Linuxattacker; two instances where a lab needs both ends of a conversation
    Ubuntu Serverthe honest host — PKI, CA and OpenVPN work in lab 07
    Metasploitable 2 / 3deliberately vulnerable target for MitM, recon and exploitation
    pfSensefirewall/router, so scans meet a real filter

    Two Kali VMs either side of a VPN is how lab 09 gets a conversation it can capture from both sides — see cia-triad. Snapshots are what make an exploitation lab survivable: the target is expected to end in an unknown state.

    Virtualisation is also the containment boundary. A self-contained virtual network with deliberately vulnerable hosts is what makes the offensive material legal and safe to run, and it is the concrete meaning of the repository's scope statement — 2022 coursework against targets provided for the purpose, nothing run against a system without authorisation.

    #The honest caveat

    A preloaded distribution makes tools available; it does not make them understood. Reading a scan's ambiguous port states, choosing between scan types, or knowing why a capture shows nothing are skills the distribution does not supply. The measurable work in this repository is mostly the crypto labs, which ran on Windows with cryptool and needed no distribution at all.
