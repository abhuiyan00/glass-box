    React

    Component library for building UIs from declarative state-to-markup functions. Used once in discrete-mathematics-laboratories — for SentinelNet, the Iberian monitoring-grid app in lab 5.

    #The unusual part: no toolchain at all

    SentinelNet is a React application with no bundler, no package.json, no node_modules, and no network fetch:

    • React and ReactDOM production UMD builds are vendored into the repo (+2,692 lines committed in 06b5882).
    • sn-app.jsx is transpiled ahead of time; the committed sn-app.js is marked "GENERATED from sn-app.jsx (do not edit by hand)" with the rebuild command in the README.
    • The result opens from file:// by double-click.

    The alternative — type="text/babel" plus the Babel CDN — was tried and broke, and the reasoning is recorded on vendor-react-over-babel-cdn. The JSX source stays the source of truth; only its output is loaded. See zero-dependency-no-build-step and offline-first-static-deliverable.

    Precompiling rather than bundling is the choice that makes this work: a build step you run manually and commit the output of is not a build step the reader has to run.

    #What it renders

    Step-frame replays of BFS and DFS, the shortest-path family comparisons (shortest-path-algorithm-family) and the bridge/articulation-point analysis (graph-connectivity-and-resilience). React's state model suits a stepper — the frame index is the state, and every panel is a pure function of it.
