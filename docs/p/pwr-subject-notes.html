    PWR Subject Notes

    The knowledge in the coursework archive that has no repository, written down — plus the census that proves nothing was quietly left out. Ten notes, one generated index over 73 subject entries / 48,815 files / 11 GB, four scripts.

    #The problem it solves

    An archive of eight semesters does not divide cleanly into things worth building and things worth forgetting. Subjects with a runnable artefact became repositories; most subjects do not have one, and earlier passes handled that by leaving them out. The result was a coverage claim that was true about the repositories and silent about everything else.

    The rule here: every subject folder gets a disposition, and an exclusion is never silent.

    #The census names its own gaps

    scripts/census.py walks the archive and prints, by name, every subject folder for which no disposition has been recorded. That is the check — not a sentence in a README claiming completeness. It is census-that-names-its-own-gaps, and it is the same shape as verify-the-load-dont-declare-it and generated-audit-artifact applied to coverage rather than to data or documentation.

    INDEX.md is generated by it. Editing the numbers by hand is not how it is updated.

    It also resolves what it prints. A row reading note: linux-laboratory is checked against notes/, a row reading repo: Physics against the sibling directories, and every note file must be named by at least one row. Added 2026-08-05 after an audit found this repository's own README claiming nine notes while notes/ held ten — never true, since the first commit contained ten, and invisible because nothing counted them. Checking both directions is the point: a missing target is a broken row, and only an orphan note catches a count that has moved.

    Re-running it writes nothing when nothing has moved. It used to stamp today's date into INDEX.md, so running the check dirtied the artefact the check was about. The date now means when these numbers last changed, and a clean git status after a census run is itself the evidence — the same move as reporting two numbers in the integrity script below.

    #Three things it found

    A census that walks subdirectories misses this archive. 2nd Semester has no subject folders at all — 116 files sit loose at its root, including the only operating-systems coursework in the archive that is not a screenshot. An earlier pass counted subdirectories and reported 80 folders and 16,066 files; counting loose files at every semester root gives 54,034. Neither figure was dishonest. The first excluded what it could not classify and did not say so, which is documentation-drift in a measurement rather than in prose.

    Four "unverified mapping" rows were checkable in one pass. 7th/TP was filed as teaching material without an assessed artefact and is in fact the requirements specification for health-awareness-support-platform. 4th semester/Sys lab was filed as unverified and its two CSV files are the inputs of air-quality-public-health-analysis. A folder name is a hypothesis; checking it moved four subjects from unknown to covered — and 5th/MAAP from assumed-covered to genuinely missing.

    An exclusion by association excluded real work. 6th/SADiSM was excluded from an earlier matrix because Bishop and Murphy sit in that folder. Excluding the textbooks was right; the four laboratory specifications and three completed solution trees beside them were excluded without being named. That folder is now systems-analysis-and-decision-support.

    #What the notes are for

    Not summaries of lecture material. Each says what a subject covered, what in it is worth carrying forward, and what was decided about it — including the decisions to build nothing:

    • linux-laboratory.md — 320 terminal screenshots, and why rebuilding them into a shell script destroys the artefact rather than preserving it.
    • software-engineering-scope-boundary.md — three folders and 1.6 M characters that would have become a third copy of information-systems-modelling. The note narrows the scope to the one thing no existing repository does: requirements traceability, pointed at a real SRS and the system that implements it.
    • unclassified-and-duplicate-folders.md — the four folders holding most of the archive by size, each unresolved in a different way, each counted rather than dropped.
    • advanced-web-technologies-and-engineering-ethics.md — the counterweight. Everything else in this archive rests on checkable claims; the ethics notes are the one subject that cannot be tested and would misrepresent the education if omitted.

    #Proving the archive is intact

    verify_archive_untouched.sh checks the immutability claim rather than asserting it, and reports two numbers because they are different claims. In the prior archive snapshot, 94 files under 5th/MAAP carry modification times after the freeze — every one a .git index or .gradle lock refreshed by inspection tooling — and zero content files changed.

    "Nothing was touched" and "no content was touched" are not the same statement, and only the second one is true. Collapsing them into one reassuring number is the failure this script exists to avoid — provenance-and-limits-stated-inline.

    #What is deliberately absent

    The ~33 million characters of extracted lecture text are a working cache and are committed nowhere: that text is the lecturers' expression. Four third-party textbooks are named and were not opened, including a 688-page pirated JEE algebra text watermarked "downloaded from jeemain.guru" on every page, found inside the algebra exercise folder. Personal, financial and assessment records are counted in the census and appear nowhere else — provenance-notice-file.

    #2026-08-12 reference audit

    With the current configured PWR archive root, the census passed and regenerated its index at 73 entries / 48,815 files / 11 GB / 10 notes, with all 73 entries carrying a stated disposition. The coverage chart regenerated from that index and was idempotent on a second run. The timestamp-based integrity check found zero files newer than the documented freeze, hence zero newer content files. The default archive paths in both check scripts now match the located archive; the WSL-provided bash cannot access Windows drive paths, so that timestamp result was verified with PowerShell using the script's same subject and exclusion rules.

    #Status

    Committed locally on main. No remote. The census is re-runnable and is the way this page's figures should be refreshed.
