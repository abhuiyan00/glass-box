    Streamlit

    A Python framework that renders a script top-to-bottom as a web app, re-running the whole script on every interaction. In labour-fraud-analysis it is the anomaly console — 219 lines in src/app.py, launched by make app, and the surface where the investigation's four signals are meant to be read.

    #Shape of the app

    • st.set_page_config(layout="wide"), then a hand-written HTML title block through st.markdown(unsafe_allow_html=True) — the framework's default chrome overridden rather than accepted.
    • @st.cache_data on a single loader that reads every CSV in data/csv into a dict of frames. The cache is what makes the re-run-everything model affordable: twenty tables parse once, not once per click. See pandas.
    • A five-metric row via st.columns(5) — people, companies, permits, documents, total structured rows — every one computed as a len() rather than typed in.
    • st.tabs(["Overview", "Anomaly dashboard", "Entity network", "Finances", "Documents"]). The anomaly tab is the analytical core; the network tab renders the networkx graph; the documents tab is the chain-of-custody surface.
    • One style(fig) helper applied to every plotly figure, holding the whole palette in five module constants. A single styling function is what keeps a five-tab dashboard looking like one artefact.

    #The disclosure banner is part of the app, not the README

    st.info renders a synthetic-data notice on the page itself, above the first chart. Someone who arrives at a screenshot or a shared browser tab, having never opened the repository, still sees the disclosure. That is provenance-and-limits-stated-inline applied to a running UI, and it is the right place for it given synthesise-rather-than-redact.

    #What it costs, and the deliberate second door

    Streamlit needs a Python process, a port, and twelve pip packages. It cannot be emailed, cannot be opened from a USB stick, and cannot be handed to a reviewer who does not run Python. That is exactly why the same twenty tables are also served by a hand-written vanilla-JS viewer with all libraries vendored and no build step — offline-first-static-deliverable and zero-dependency-no-build-step — and by a notebook that CI executes end-to-end (reproducible-analysis).

    Three surfaces over one dataset is a real cost: the four signals are implemented three times, and the bulk-permit threshold is hard-coded identically in all of them plus the test suite.
