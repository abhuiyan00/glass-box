    Dual License — MIT Code, CC BY Data

    Decision. License the repository under two licences at once: MIT for everything executable, Creative Commons Attribution 4.0 for the dataset and the written analysis. Keep the LICENSE file as canonical unmodified MIT and put the split in NOTICE.

    Date. 2026-07-11, labour-fraud-analysis — arrived at in the repository's final commit.

    #Why

    "Code (everything under /src, /interactive, /notebooks, and the build tooling) is released under the MIT License; see LICENSE. The dataset and prose (everything under /data and /docs) are released under Creative Commons Attribution 4.0 International (CC BY 4.0); see LICENSE-DATA."

    labour-fraud-analysis-a-forensic-data-investigation/NOTICE, 2026-07-11

    The two halves of this repository are different kinds of thing. src/ is machinery — an anonymisation pipeline, a disclosure gate, a doc generator — that someone might reasonably lift into their own project, where MIT's near-zero friction is the point. data/ and docs/ are a citable artefact: a 20-table dataset and a long-form narrative, whose value is as something to reference, and where attribution is not friction but the whole transaction. Software licences map badly onto datasets; CC BY is built for the case.

    There is a second reason specific to this repository. CC BY's attribution requirement travels with the data, and LICENSE-DATA uses the space to carry the synthetic-data disclosure into any reuse:

    "IMPORTANT — SYNTHETIC DATA NOTICE"

    labour-fraud-analysis-a-forensic-data-investigation/LICENSE-DATA, 2026-07-11

    A dataset extracted from this repo and dropped into someone else's analysis arrives with a machine-adjacent statement that every value in it is fictional. Given synthesise-rather-than-redact, that is the disclosure most likely to be lost in transit and the one most worth attaching to the licence file. It is the same instinct as provenance-and-limits-stated-inline, applied where prose usually is not.

    #How it is structured

    File Covers
    LICENSEcanonical, unmodified MIT — /src, /interactive, /notebooks, build tooling
    LICENSE-DATACC BY 4.0 — /data, /docs, with the synthetic-data notice and an attribution string
    NOTICEthe split itself, plus the synthetic-data statement, read first

    Keeping LICENSE textually canonical matters for tooling: GitHub's licence detection and every SPDX scanner recognise unmodified MIT and fail on a hand-edited variant. The scoping lives in NOTICE precisely so the licence file itself stays machine-identifiable.

    #Alternatives rejected

    Option Why not
    A single edited LICENSE carving out the databreaks automated licence detection; the final commit explicitly undoes this shape
    MIT over everythinga software licence that says nothing useful about attributing a dataset or a narrative
    CC BY over everythingdiscourages lifting the pipeline code, which is the reusable part
    No licence on the datadefault is all-rights-reserved; the dataset then cannot be cited or reused, which defeats publishing it

    The first row is the one the repository actually walked. The eighth and last commit reads "Simplify the LICENSE to canonical MIT and note the dual license in NOTICE" — a licence file that had been modified was restored to canonical form and the scoping moved out of it.

    #Confidence and gaps

    confidence: medium. The arrangement is unambiguous — three files agree and the README repeats it. The reasoning above is reconstructed from what the files do; the repo states the split but never argues for it.

    Note the tension worth holding. The repository licenses its dataset for open reuse, while every page about it in this wiki is publish: false pending clearance from the corpus holder. A permissive licence is the author's grant over the derived artefact; it is not evidence of permission over the source it derives from. Those are separate questions and the wiki treats them separately — see labour-fraud-analysis and disclosure-gate.
