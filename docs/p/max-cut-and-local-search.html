    Max-Cut and Local Search

    Max-Cut: partition a graph's vertices into two sets so that the weight of edges crossing between them is maximised. NP-hard. With 127 vertices the space of partitions is 2^127, which the lab states explicitly as the reason exhaustive search is off the table — the reasoning is recorded on heuristic-over-exact-max-cut.

    #The heuristic actually used

    Best-improvement local search with random restarts.

    1. Start from a random assignment of vertices to the two sides.
    2. Compute, for every vertex, the gain from moving it to the other side.
    3. Move the single vertex with the largest positive gain. Repeat until no move improves — a local optimum.
    4. Restart from a fresh random assignment. Ten restarts; keep the best local optimum found.

    The restart loop is the whole point: a single descent lands wherever its starting point drains to, so multi-start converts a deterministic local method into a crude global one. The repo records a conclusion about multi-start effectiveness in its own commit history (Add conclusion about multi-start heuristic effectiveness, 2026-03-20).

    Best-improvement — scan all candidate moves, take the best — differs from first-improvement, which takes the first improving move found. Best-improvement costs a full scan per step and tends to need fewer steps; the lab uses it without recording a comparison.

    #Why it belongs in a discrete-maths course

    Max-Cut is the standard worked example of the gap between stating an optimisation problem and solving it. The definition is one line; the exact solution is intractable; a twenty-line heuristic gets useful answers. Running it and watching the cut value climb per restart is what make-the-formal-object-observable means in discrete-mathematics-laboratories.

    #Implementation notes

    Pure Python stdlib — random and re, no numpy, no solver library. The graph arrives in a custom V/E text format parsed by a hand-written reader, so the lab also owns its input format rather than depending on DIMACS tooling.

    #Related

    Local search under a different name and a much larger apparatus appears in optimization-methods, where the same restart-and-perturb idea drives vehicle routing and flow-shop scheduling. Max-Cut is the minimal version of that machinery.
