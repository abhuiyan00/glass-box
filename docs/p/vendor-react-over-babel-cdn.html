    Vendor React Over the Babel CDN

    Decision. Commit React and ReactDOM's production UMD builds into the repository and precompile sn-app.jsx to sn-app.js ahead of time, rather than loading Babel from a CDN and transpiling JSX in the browser.

    Date. Committed 2026-07-10 as 06b5882 Make SentinelNet run offline: vendor React, precompile the JSX — 2,692 insertions.

    #Why

    The CDN approach did not merely degrade offline, it produced nothing at all:

    "It used to be loaded through the Babel CDN with type=\"text/babel\", so opening it directly (file://) left a blank page — the browser blocks Babel from fetching the local .jsx, and there was no internet fallback."

    Discrete-Mathematics-Laboratories/lab5_GraphTheory/README.md, 2026-07-10

    Two independent failures stacked: the CDN needs the network, and in-browser Babel needs to fetch() the .jsx file, which file:// origin rules forbid. A deliverable that must open by double-click on a marker's machine — offline-first-static-deliverable — cannot depend on either.

    #Alternatives rejected

    Option Why not
    Babel CDN + text/babelthe incumbent; blank page on file://, no offline fallback
    A local dev servermoves the failure to "the reader must start a server"; defeats double-click delivery
    A bundler (Vite/esbuild)introduces node_modules and a build the reader must run
    Drop React, use vanilla JSwhat lab4/part2 and lab6/viewer already do — not taken here

    TODO: how the blank page was discovered (a failed demo? marking?) and whether a dev server or bundler was actually tried before committing the precompiled output is not recorded anywhere. confidence: low on the process; confidence: high on the decision and its stated reason.

    #The safeguard that makes it survivable

    Committing generated output invites drift, so the source relationship is written down:

    "sn-app.jsx remains the source of truth. To rebuild sn-app.js after editing it, transpile the JSX (any Babel with preset-react)"

    Discrete-Mathematics-Laboratories/lab5_GraphTheory/SentinelNet/README.md, 2026-07-10

    The generated file carries a "GENERATED from sn-app.jsx (do not edit by hand)" header and the rebuild command lives in the README. See react.

    #Consistency check

    The sibling app in the same lab directory does the opposite — Q-HYDRO Wrocław states "No dependencies are vendored" and loads Leaflet, tiles and fonts from CDNs. Two lab-5 apps under opposite rules, and the root README's "all run offline" overstates it. See zero-dependency-no-build-step and documentation-drift.
