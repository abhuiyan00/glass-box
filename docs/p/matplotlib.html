    matplotlib

    Python's plotting library. It appears in both lab repositories in two clearly different modes, and the split is the interesting part.

    #Mode 1 — interactive explorer (Discrete Maths)

    In discrete-mathematics-laboratories matplotlib is the interface, not the output format:

    • GridSpec dashboards — several linked panels in one figure rather than separate plots, so a value and its cost are read together.
    • Slider widgets over the parameters, in labs 2 and 4. Changing m and n and watching the recursive call count move is the deliverable — see ackermann-and-primitive-recursion.
    • LogNorm colour scaling on heatmaps, which is mandatory rather than cosmetic here: Ackermann values and factorization timings span so many orders of magnitude that a linear scale shows a single hot cell and nothing else.
    • Benchmark curves for RSA attack runtime and success rate against key size — rsa-and-integer-factorization.

    This is make-the-formal-object-observable in library form.

    #Mode 2 — headless figure generation (Python labs)

    In python-programming-laboratories lab 11 it is a batch renderer inside a document pipeline:

    • The Agg backend — no display, no GUI event loop, correct for a script that produces files.
    • plt.close() per figure, across 41 chapters. Without it the figure manager retains every figure and memory climbs until the run dies; this is the standard matplotlib leak and the pipeline handles it explicitly.
    • Output goes to a gitignored charts/ directory, reproducible from source rather than committed.

    Alongside pillow for cover images and BeautifulSoup for the source text, see beautifulsoup.

    #Note

    Neither repo pins a matplotlib version. In Discrete Maths it arrives with numpy as an ambient scientific-Python assumption; in the Python labs it lives in the optional labs extra, keeping the core package dependency-free — setuptools-and-pyproject.
