    Make the Formal Object Observable

    Take a mathematical definition and build something that lets you watch it behave. Not a write-up with worked examples — a program with a slider, a stepper, or a failure simulation. The repository states this as its own organising thread:

    "The thread running through all six: take a formal object (a cut, a modulus, a set, a recursion, a graph, an information system) and make its behaviour observable."

    Discrete-Mathematics-Laboratories/README.md, 2026-07-10

    The verb is observable, not illustrated. The distinction is that the reader supplies the input.

    #Six instances, one per lab

    Formal object What you can watch
    A cutthe best cut value climbing across ten random restarts — max-cut-and-local-search
    A modulusFermat's attack collapsing as `\p−q\` shrinks — rsa-and-integer-factorization
    A setχ-sums, truth tables and inclusion–exclusion agreeing — characteristic-functions
    A recursionthe call counter exploding while the value barely moves — ackermann-and-primitive-recursion
    A graphnodes failing one by one until the network splits — graph-connectivity-and-resilience
    An information systema query and its result rendered side by side — pawlak-information-system

    #The recurring mechanics

    • A control, not a constant. matplotlib Slider widgets over m/n; Colab #@param form fields; a browser panel of lenses. The parameter that carries the concept is the one exposed.
    • Show the cost beside the answer. A recursive-call counter, a 2^127 search space quoted next to a ten-restart heuristic, live graph metrics — the price of the computation is part of the observation.
    • Steps, not results. BFS and DFS render as replayable step-frames rather than a final ordering.
    • Failure as an interaction. Q-HYDRO's stackable node failures make connectivity theory something you break rather than read.
    • Scales chosen so something is visible. LogNorm heatmaps, log-space evaluation via lgamma — a linear axis on Ackermann values shows one hot cell and nothing else.

    #Why it is a pattern and not a preference

    Because the same instinct survives outside the maths course. course-as-runnable-study-tool is this pattern applied to exam revision across four other repositories; the deliverables are double-click HTML for the same reason — offline-first-static-deliverable. The cost is real: discrete-mathematics-laboratories has essentially no automated tests, because effort went into making behaviour visible to a human rather than assertable by a runner. Observability substituted for verification.
