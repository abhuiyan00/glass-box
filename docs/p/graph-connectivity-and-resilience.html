    Graph Connectivity and Resilience

    "Is this network connected?" is a yes/no question. "What breaks it?" is the useful one, and it has precise graph-theoretic answers. Both lab-5 applications in discrete-mathematics-laboratories are built around turning those answers into a failure simulation.

    #The structural vocabulary

    Object Definition Operational meaning
    Bridgeedge whose removal disconnects the grapha single link with no redundancy
    Articulation pointvertex whose removal disconnects the grapha single node whose loss splits the network
    Edge connectivity κ′(G)minimum edges to cuthow many simultaneous link failures survive
    Biconnected componentmaximal subgraph with no articulation pointa region that tolerates any one node loss

    Tarjan's algorithm finds bridges and articulation points in one DFS pass by tracking each vertex's discovery time and the lowest discovery time reachable from its subtree — the low value. An edge (u,v) is a bridge when low[v] > disc[u]; no cross-edge climbs back past u.

    #The honest bound

    The lab does not pretend to compute κ′(G) properly, and says so in the source:

    "// For this dataset: if any bridge exists, κ'(G) = 1; otherwise treat as 2 (a conservative placeholder — a full Stoer-Wagner cut is out of scope)."

    Discrete-Mathematics-Laboratories/lab5_GraphTheory/SentinelNet/sn-algo.js, 2026-06-09

    That is a correct lower-bound argument stated as a limitation rather than dressed up as a result — the pattern is provenance-and-limits-stated-inline.

    #Two applications of the same machinery

    SentinelNet (Iberian monitoring grid) also computes bipartiteness by 2-colouring, clustering coefficient, diameter and radius, Euler status with a greedy Chinese-Postman pairing, Hierholzer's tour construction, and both Prim and Kruskal spanning trees (Kruskal over a path-halving union-find — see ackermann-and-primitive-recursion for why that is effectively constant time). BFS and DFS are rendered as replayable step-frames, not as final answers.

    Q-HYDRO Wrocław (25-node Lower-Silesia gravimeter mesh) uses the same primitives for a stackable node-failure simulation: fail nodes cumulatively, recompute connectivity, and propose the cheapest link augmentation that repairs it by a greedy min-cost rule. It also checks planarity via the Euler bound E ≤ 3V − 6 — a necessary condition, not a planarity test, which the app is careful about. Its data.js is a single source of truth with every displayed figure recomputed on load rather than hard-coded.

    #Finding: not actually Christofides

    sn-algo.js names a function tspChristofides, but it matches odd-degree vertices greedily instead of by minimum-weight perfect matching. The 1.5-approximation guarantee depends entirely on that matching being optimal, so the guarantee does not hold. It should be read as a Christofides-shaped heuristic.
