    SQLite

    An embedded SQL database: one file, no server, no configuration, and a driver in Python's standard library as sqlite3. That combination is why it shows up wherever a project needs real SQL without asking the reader to install anything.

    #Labs 13/14 — Python Programming Laboratories

    A knowledge-corpus browser in python-programming-laboratories, backed by a tkinter GUI. The database-side choices:

    • Idempotent load via UNIQUE(context, knowledge, response) plus INSERT OR IGNORE. 610 rows on the first run, 0 on the second — see idempotent-loading. Uniqueness lives in the schema, not in the loader, which is the part that survives concurrency.
    • Parameterised queries throughout. Placeholders rather than string interpolation, so a value containing a quote is data and never syntax. The reason to be strict about it in a teaching repo is visible one lab away: the sample access log in data/ contains an actual injection attempt, see common-log-format-parsing.
    • The connection is opened in main() and closed by contextlib.closing, never at import — separating-computation-from-io.
    • The .db file is written into a gitignored build/ directory, "reproducible from source" rather than committed.

    #Also used as a reference implementation

    SQLite carries the reference implementation in data-warehousing-and-business-intelligence, where the warehouse logic is expressed in portable SQL against a file database before or beside the vendor stack. That is SQLite's other characteristic role: a zero-setup executable specification that anyone can run to check what the real system is supposed to produce. confidence: medium here — recorded from the cross-repo signal rather than read in full.

    #Trade-off worth stating

    Single-writer locking and dynamic typing are the costs; no server, no ports, no credentials and a database you can email are the benefits. For coursework deliverables and for reference implementations, the trade lands decisively on SQLite's side — the same logic as zero-dependency-no-build-step.
