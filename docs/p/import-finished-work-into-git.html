    Import Finished Work Into Git

    Work is built to completion outside version control, then imported in a burst. Git holds the artefact, not the process. Confirmed in 11 of 15 source repositories, contradicted in two, and split in one — which makes it the single strongest signal about how this developer works.

    #Why this matters to the wiki

    The real working log lives somewhere else, and it is richer than git:

    • browser_game_stickfps/PROGRESS.md — 40.5 KB, eleven post-launch rounds, every dead end
    • Farley/docs/ocr-overlay/CHANGELOG.md — dated entries for 2026-07-02/03 that predate the repo
    • IT Applications in Business and Commerce/project/docs/branch-reports/ — 846 lines auditing a different repository's eight branches
    • Optimization Methods/final_project/docs/DATA_VERIFICATION.md — "Date of check: 2026-07-09"

    Commit messages describe artefacts ("Add the React Three Fiber game client"), never work. So the session layer and these in-repo logs are the only records of why — see progress-md-as-build-log and branch-per-experiment.

    #What the bursts actually were

    Not a portfolio push and not a submission deadline:

    "Just cleaning up local folders."

    interview, 2026-07-28

    The clustering on 2026-07-10 and 2026-07-25 is consolidation, incidental to any external event. Earlier drafts of this analysis read the batching as release events; the interview corrected that. Git here is a storage channel, distinct from the publishing step in presentation-polish-tail-commits.

    #The counter-examples

    Two repos genuinely contradict the pattern, and both are course-long:

    • Discrete-Mathematics-Laboratories — 49 commits, 2026-03-20 → 07-10, five working dates with real gaps, and commits that exist only because something broke: 48ba16d Fix UnicodeEncodeError in the lab3 demos on Windows consoles, 06b5882 Make SentinelNet run offline: vendor React, precompile the JSX, 8a2acfe … stop tracking compiled bytecode.
    • Optimization Methods — 69 commits over 105 days, author date == commit date throughout, four cross-machine merges, and a traceable mid-stream fix (d72e8bf fixed no run on tabu search on high talliard instances). Split verdict: first_project is a real working log; final_project and exam_prep arrived as single squashed commits after an 81-day silence.

    Even in the contradicting repos, within-session granularity stays upload-shaped — nine lab-3 files each in their own commit, message equal to the file path; one commit is literally Add files via upload from the GitHub web UI.

    #Caveat on the survey

    brain.py survey reported Discrete-Mathematics-Laboratories as first = last = 2026-07-10, hiding a four-month history. The survey's git dates are unreliable; every date on the wiki pages was taken from git log directly.
