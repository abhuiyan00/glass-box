    Capacitor

    Native runtime that wraps a web build in a WebView and exposes native capability through plugins. Used at 7.6.7 in farely as the Android host, and nowhere else in the source set.

    #How Farely uses it

    capacitor.config.json: appId com.farely.app, appName Farely, and — the load-bearing line — webDir: "../tester/dist". The APK does not contain its own web app; it points at the Vite build of the sibling workspace package. One bundle serves the browser simulator and the phone, which is what makes pure-domain-engine-shared-across-hosts possible rather than aspirational.

    Native project under apps/android/android: AGP 8.7.2, Kotlin Gradle plugin 2.0.21, jvmTarget 21, Gradle 8.11.1, minSdk 23, compileSdk/targetSdk 36, cordova-android 10.1.1.

    #The custom plugin

    FarelyBridgePlugin is the whole reason Capacitor is here rather than a plain PWA. It carries RawOffer data out of the android-accessibility-service into the WebView, and the verdict back in so OverlayController can draw it. Capacitor's plugin surface is the only part of the native platform the web layer touches directly, besides CapacitorHttp — used by vision.ts to reach the anthropic-messages-api without a browser CORS preflight.

    #Why it fits this shape of app

    The product is ~12,100 lines of TypeScript UI and domain logic against ~1,099 lines of Kotlin doing capture and drawing. A framework that treats the web app as primary and native as an extension matches that ratio. React Native or a fully native rewrite would have inverted it for no gain — the accessibility service is plain Android code either way, and it is the only genuinely native part.

    #Friction it introduces

    The gradle project resolves @capacitor/android through a relative ../node_modules path, which makes the package manager's hoisting layout part of the build contract — the entire subject of pnpm-over-npm-for-capacitor-gradle-path and pnpm. Build chain is two-step and slow: vite build (≈309 kB, with maplibre-gl split into its own ~1 MB chunk), then npx cap sync, then gradlew assembleDebug (4.0 MB debug APK, 6m31s cold).
