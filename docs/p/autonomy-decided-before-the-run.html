    Autonomy Decided Before the Run

    Three levels — readonly, auto (default), full — chosen in settings or from the panel before a task starts, and passed to both executors as flags. There is no per-action approval, because there is nowhere to put one.

    #Why there is no Allow button

    Both CLIs are spawned non-interactively so their output can be parsed as structured events (drive-the-clis-not-the-apis). A non-interactive process has no one to ask. Adding approval would mean either running the CLIs interactively — giving up the structured stream that everything here depends on — or building a proxy that intercepts tool calls, which is the agent loop this project decided not to write.

    Parallelism makes it worse rather than better: three agents in a wave produce three interleaved prompts about work the user cannot see, which is not consent, it is a queue of guesses.

    So the control that remains is honest defaults, visible level, before the fact:

    Level claude-code-cli codex-cli
    readonly--permission-mode plansandbox_mode=read-only
    autoacceptEdits + an allow-list of build/test/inspect commandsworkspace-write
    fullbypassPermissionsdanger-full-access

    #The claim that is deliberately not made

    The documentation states plainly that this is not a sandbox. The levels are the vendors' own enforcement, and full is exactly what its name says. What the design does offer is one structural property that survives even at full: the router — the only component that reads every subtask's output — has no tools at all, so text that persuades it can produce a wrong answer but cannot produce an action.

    Saying "this is not a sandbox" out loud is the actual decision. A security section that oversells what it enforces is worse than none, because it converts a user's caution into misplaced confidence.

    #Rejected

    Per-action approval. Costs the structured stream, or the whole agent loop. A single "yolo" boolean. Two states cannot express "may run the test suite, may not run anything". Sandboxing the CLIs here (containers, seccomp). Out of scope for an editor extension, and a half-sandbox invites the overclaim above.
