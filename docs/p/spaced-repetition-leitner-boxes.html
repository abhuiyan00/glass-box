    Spaced Repetition with Leitner Boxes

    The cheapest possible spaced-repetition scheduler: every card sits in one of five numbered boxes, each box has a fixed review interval, a correct answer promotes the card one box, and a wrong answer sends it straight back to box 1. No difficulty rating, no ease factor, no per-card history — the box number is the memory.

    #The implementation in physics-exam-prep

    js/app.js is 82 flashcards and about ten lines of scheduler:

    const SR_INTERVALS=[0, 0, 8*60, 24*3600, 3*24*3600, 7*24*3600]; // sec, index by box 1..5
...
box = good ? Math.min(5,box+1) : 1;
const due = Date.now() + SR_INTERVALS[box]*1000;
    Box Next review Meaning
    1immediatelymissed, or never seen
    28 minutessame-session re-check
    31 dayovernight consolidation
    43 days—
    57 days"mastered"; the dashboard counts box-5 cards as the mastery number

    Per-card state is {box, due} in localStorage under physprep.v1. The deck is ordered due-first, then by box, so the weakest material is always on top. The dashboard renders the box distribution as five pills plus a due count, which turns the scheduler into the progress metric — there is no separate notion of "cards learned".

    #Why this shape fits the constraint

    Leitner is the algorithm you choose when the deliverable must run with no network, no server and no account — offline-first-static-deliverable. SM-2 and its descendants need a per-card ease factor and a review log to converge; Leitner needs one integer. It survives a cleared localStorage by resetting to box 1 for everything, which is the correct failure mode for a study tool and needs no recovery code.

    The interval ladder here is also tuned to the actual use: 8 minutes for box 2 is not a memory interval, it is a same-sitting re-check. Combined with the app's own honest estimate of ≈35–45 hours of study over 2–3 weeks, the 7-day top interval means a card can reach "mastered" roughly twice inside the study window — the ladder is sized to the exam, not to long-term retention.

    #Placement

    One of the recurring components of course-as-runnable-study-tool, alongside localStorage progress, hash routing and a generated question bank. Only the Physics instance implements Leitner boxes; the sibling apps track progress without a repetition schedule.
