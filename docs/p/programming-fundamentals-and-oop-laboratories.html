    Programming Fundamentals and OOP Laboratories

    Compact laboratory modules for object-oriented modelling in Java 21 and explicit ownership in C++20. The Java module models typed inventory containers; the C++ module implements a reference-counted pointer and a tree with stable node addresses. There is no application to deploy: the public contracts and their tests are the deliverable.

    #Java inventory contracts

    Container measures capacity in units rather than storage slots, retains immutable Item values, and exposes an unmodifiable contents view. Its label() method supplies polymorphic rendering without duplicating toString() in each subclass. Admission either takes a complete item or returns false; callers retain control over any smaller split they want to make.

    The Java tests exercise aggregate totals, order-independent admission, parsing choices, and subclass rendering. This keeps domain rules executable instead of leaving them only in example output.

    #C++ ownership and trees

    owning_ptr uses separate specialisations for a single object and an array, so the allocation shape and matching release operation are fixed by the type. Copy-and-swap assignment acquires the incoming shared state before releasing the old state and also makes self-assignment safe. The type intentionally does not promise thread safety.

    The tree holds children through std::unique_ptr; growing the child vector moves pointers, not nodes, so an accepted child address remains stable for that node's lifetime. move_subtree refuses root, self, null, and descendant moves to preserve one rooted acyclic ownership tree. Explicit deep copy keeps separate trees independent.

    #Verification

    On 2026-08-12, Java 21 Maven verification passed 27/27 tests. A fresh CMake C++20 build completed with warnings treated as errors, and both native test binaries passed (2/2).

    The C++ tests make lifetime observable with tracked.hpp, rather than requiring a sanitizer runtime on every supported toolchain. Sanitizers remain an opt-in CMake check (-DFUNDAMENTALS_SANITIZE=ON) and are an independent additional signal.

    #Boundaries

    These are deliberately small laboratory libraries, not a framework or an application. The tree tests exercise representative structural cases; property-based generation is not part of the current suite. Coursework provenance and the clean-room boundary are stated in the repository NOTICE.
