    React Three Fiber

    A React renderer for three-js: the scene graph is expressed as JSX components and reconciled like a DOM tree. Used in stickfps at @react-three/fiber ^9.6.1, with @react-three/drei ^10.7.7 for helpers and @react-three/postprocessing ^3.0.4 for the effect chain, on react ^19.2.7.

    #What it buys here

    One tree for HUD and world. Lobby, HUD, buy menu, pause menu and match-end screen are ordinary React components sharing state with the 3D scene through the same hooks — there is no bridge between a UI framework and a render loop, which is the usual source of duplicated state in browser games.

    useFrame as the render loop. The per-frame callback is where the client's accumulator lives: useFixedTimestep drains simulated steps from the frame delta, so fixed-timestep-simulation runs inside React's loop rather than beside it.

    Escape hatches stay available. Effects, object pools (pooling/ObjectPool.ts), tracers and particles are managed imperatively where per-frame allocation would matter, and mounted declaratively where it would not.

    #Where the abstraction leaks

    React batching can eat a game event. In stickfps the kill feed can drop an entry when two lethal hits land inside the same React batch — two state updates collapse into one render and one of the messages never appears. This is reported and deliberately not fixed. The general lesson: a UI-state model tuned for "latest value wins" is the wrong shape for an event log, which needs append semantics, and the bug only appears under simultaneity.

    Bundle weight. The client ships ~1.4 MB, listed in the repo's own limitations.

    Testability splits cleanly, and that is the tell. Client tests in stickfps cover pure functions only — movement controller, weapon state machine, spring integrator, object pool, reconciliation, interpolation. Anything requiring a real GL context is verified through playwright instead. Keeping simulation logic out of components is what makes that split possible.

    #Version note

    The vendored R3F skill pack in the repo declares Requires @react-three/fiber 8.x+ while the project runs 9.6.1 — see agent-skills-checked-into-the-repo and documentation-drift.
