    Keep the Teaching Version

    Decision. Keep labs/04_classes/ — the hand-written HttpRequest / CorrectHttpRequest / MalformedHttpRequest hierarchy — in the tree alongside weblog.LogEntry, which does the same job better and is what everything else actually imports.

    Date. 2026-07-25, python-programming-laboratories.

    #Why

    "weblog.LogEntry is the version the rest of the repository uses; the classes here are the teaching version, kept because writing the special methods by hand is the exercise."

    Python-Programming-Laboratories/labs/04_classes/README.md, 2026-07-25

    The two are not competing implementations where one won. weblog.LogEntry is @dataclass(frozen=True, slots=True) — the decorator generates __eq__ and __hash__ consistently and blocks mutation, in one line. The lab-04 classes write __eq__ (returning NotImplemented for foreign types), an explicit __hash__, total_ordering, and a from_line classmethod factory by hand. See pythons-data-model.

    Deleting the hand-written version once the dataclass exists would delete the reason the dataclass is correct. The generated version is only trustworthy to someone who knows what it generates.

    #What makes it safe rather than confusing

    The redundancy is declared and directional. The README states which one is authoritative and why the other exists, in the directory where a reader would otherwise be misled. An undocumented second implementation is a trap; a labelled one is a reference.

    This is dual-implementation-as-cross-check applied for pedagogy rather than verification, and a close relative of keep-the-superseded-version-in-tree — with the difference that nothing here is superseded. Both remain correct; only one is used.

    #Alternatives rejected

    Option Why not
    Delete lab 04 after extracting weblogdestroys the exercise the lab exists to record
    Rewrite lab 04 to import LogEntrythe whole point is writing the dunders by hand
    Leave both with no notea reader cannot tell which is authoritative — the actual failure mode

    #The residual hazard

    labs/04_classes/requests.py shadows the requests package that labs 10 and 11 import, if that directory ever lands on sys.path. confidence: high — a real cost of keeping a parallel tree, and the one thing about this decision that is not free. See beautifulsoup.
