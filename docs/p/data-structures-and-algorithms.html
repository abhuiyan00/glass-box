    Data Structures and Algorithms

    A Java 21 library in which every complexity claim is a test rather than a comment. Built from the fifteen-lecture syllabus of the sixth-semester DSAA course, clean-room, with no historical source carried across. 224 JUnit 5 tests, offline Maven build, no runtime dependencies.

    #The one decision everything follows from

    Count operations; never measure wall-clock time. See counted-complexity-assertions for the general idea and clean-room-rebuild-from-specification for why the code is new.

    Every structure takes a Counter and charges itself for each comparison(), move() and probe(). A test then runs the algorithm over a doubling series of sizes, fits the measured counts against seven candidate growth functions after dividing out the best constant, and fails if the fit disagrees with the javadoc. Counts are deterministic for a fixed input, so the same assertion passes identically on a fast machine, a loaded CI runner, and a laptop on battery — which a timing assertion cannot.

    #Two documented claims that the measurement contradicted

    Both were corrected in the class comments rather than by loosening the assertion, which is the rule recorded in AGENTS.md.

    Repeated heap insertion is not linearithmic on typical input. The textbook O(n log n) is a worst-case statement, routinely repeated as though it described the typical case. On shuffled keys the fit comes out linear, because a random key lands near the bottom of the heap and sifts up barely one level. The gap appears only on descending keys, where every insertion is a new minimum; the suite now asserts both directions.

    Linear probing does not merely slow down — with the wrong keys it stops being constant per operation. With keys "key0".."key8191", whose hashes are nearly consecutive, its measured total is neither linear nor monotonic in n, while double hashing on the same keys is a clean straight line. Linear probing was removed from the shared amortised-constant test and given a dedicated one, rather than the shared assertion being relaxed for every implementation.

    A third result is about the instrument rather than the algorithms: n/4 + 1000 classifies as constant at n ≤ 512 and linear at n ≥ 8192. The fitter is right both times — asymptotic behaviour is a claim about large n, and a measurement at small n is entitled to disagree. The disagreement is a test, not a workaround.

    #Failure modes are tests, not warnings

    An adversarial hash whose every key collides; a delete that would orphan the rest of a probe run without tombstones; sorted insertion degenerating a search tree to a linked list with extra pointers; greedy change-making on {1, 3, 4} where the optimum is 3 + 3 and greedy takes 4 + 1 + 1. A structure whose guarantee is conditional is measured on the input that breaks the condition — the same habit as document-the-failure-mode-next-to-the-fix, enforced by the suite rather than by prose.

    Making the cost of an operation part of its signature is make-the-formal-object-observable applied to complexity: the Counter parameter is intrusive on purpose, because a cost nobody can see is a cost nobody checks.

    #Verification

    A 2026-08-12 local audit passed Maven compilation and all 224 JUnit tests under JDK 21. Maven needed the process-local user.home set to the owner profile because the sandbox reports C:\ as Java's home; that is environment configuration, not a code change. The existing SVG and its precise README caption were preserved because they carry exact suite measurements rather than decorative estimates.

    #Status and provenance

    Local repository on main, one commit, not pushed. The syllabus supplied the topic list and nothing else; see NOTICE and provenance-notice-file. Deliberate next steps in TASKS.md — a red-black tree beside the AVL tree, a B-tree counting node accesses rather than comparisons, an indexed priority queue to measure the constant-factor trade that lazy deletion currently takes on trust in Dijkstra and Prim, and a space counter for the memory claims that are still only prose.
