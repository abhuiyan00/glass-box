    Characteristic Functions

    The characteristic function χ_A(x) of a set A over a universe U returns 1 when x ∈ A and 0 otherwise. It is the bridge between set algebra and ordinary arithmetic: every set operation becomes a pointwise numeric operation on 0/1 vectors.

    The four identities lab 3 of discrete-mathematics-laboratories implements and checks:

    χ_(A∩B)(x) = min(χ_A(x), χ_B(x))
χ_(A∪B)(x) = max(χ_A(x), χ_B(x))
χ_(A′)(x)  = 1 − χ_A(x)
|A|        = Σ_{x∈U} χ_A(x)

    The last one is the payoff: cardinality is a sum. Once a set is a vector of indicators, counting, intersecting and complementing are all arithmetic, which is why bitsets, Bloom filters and columnar database predicates all work the way they do.

    #What the lab builds around it

    • Set, MultiSet and EmptySet implemented from scratch over native lists, not Python's builtin set — the exercise is owning the operations, not calling them.
    • Power set and Cartesian product constructors.
    • Inclusion–exclusion: |A∪B| = |A| + |B| − |A∩B|, verifiable against the χ-sum definition above, which is the cleanest way to see why the correction term exists.
    • A propositional parser producing truth tables — the logical twin of the same machinery, since a truth table is a characteristic function over assignments.

    #The only automated check in the repo

    lab3_Sets/mandatory_tasks/test_suite.py is a hand-rolled TestRunner: boolean assertions, ✓/✗ output, a pass/fail summary returning a bool. Not pytest — this repo has no test framework and no CI. It is nevertheless the only place in discrete-mathematics-laboratories where a claim is machine-checked rather than screenshotted.

    A related commit records what running it on Windows cost: 48ba16d Fix UnicodeEncodeError in the lab3 demos on Windows consoles — the ∈ ∪ χ Σ glyphs printed in the demos are not safe on a cp1252 console. See document-the-failure-mode-next-to-the-fix.
